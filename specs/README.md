# Ragon Technical Specification

> - **Version:** 0.9.0 (`dreamference.__version__`), the first release ([RELEASE_0.9.0](./DREAMFERENCE_RELEASE_0.9.0.md)).
> - **Target Hardware:** NVIDIA GB10 (Blackwell SM121, 128 GB unified memory)
> - **Deployment Model:** single node, with the model, the code and the sessions on the machine. Not air-gapped by default: web search, page fetch and Gmail use the internet unless `/airgapped on` ([RAGON_AIRGAPPED](./DREAMFERENCE_RAGON_AIRGAPPED.md)); a GB10 offered to the local network with `ragon-admin node enable` serves clients that find it over mDNS ([RAGON_NODE](./DREAMFERENCE_RAGON_NODE.md), Parts 1–3 built in part; two GB10s paired, §18.10)
> - **License:** AGPL-3.0-or-later
> - **Specs last reconciled with the code:** for 0.9.0; the descriptive specs were checked against the parser, the model registry and the source tree.

This directory holds the specification, split into focused documents. This page is the index.

**Where the old monolith went:** earlier versions of this file also carried the whole pre-split specification, about 900 lines, below the index. That copy had drifted from the code on nearly every point (default agent, CLI commands, models, recipes), and it duplicated the modular documents. It was removed; it is in git history if needed.
