# `ragon-admin`'s commands

Developer notes behind the command lines in `AGENTS.md`. `ragon-admin` is `dreamference.cli:main`; its parser and dispatch are `dreamference/cli/dreamference_cli_controller.py`. A client install has no `ragon-admin` (node-only): clients use `ragon node list`, `ragon node use` and `ragon exec`.

## Every subcommand

`init`, `run`, `status`, `index`, `mcp`, `web`, `endpoints`, `searxng {start,status}`, `codex {build,start,stop,test}`, `code {setup}`, `docs {setup}`, `gmail {search,read,status}`, `google {start,stop,status}`, `profile …` (forwards every argument to the `ragon-profile` binary beside `ragon`; says so when it is not built; `benchmark_server` was retired for it and answers with a pointer, exit 2, for one release), `night {enable,disable,status,run,autofill,every {add,list,drop},archive,pause,resume}` (`night every --<cadence> …` is short for `night every add --<cadence> …`), `host {check,setup}`, `forge {status,on,off,move,promote,backup,restore,key add,github-mirror,password,import,archive,mirrors}` (plus `run` and `tick`, the forge unit's and its timer's) ([forge.md](forge.md)), `node {enable,disable,status,id,list,add,remove,set,start,stop,sync-model,run,jobs,logs,cancel,fetch,power-cycle,power-config {plug,node,show},provision,prepare}` (plus `authorize`, `serve-job`, `job-exec` and `askpass`, which no person types), `swe-bench {setup,build-images,smoke,run,eval,report,status,clean,pin-images,shard,merge}`, `audit {egress}` (`--tui`, `--app`, `--web`, `--compat claude`, `--docs`, `--sync`, `--prompt`, `--ragon-docs-bin`, `--json`), `logs {server,mcp}`, `benchmark_server`, `server {start,stop,remove,logs}`, `images {start,stop,status,mcp}`, `voice {start,stop,status}`, `remote {setup,status,remove,code,peers,revoke,certificate {issue,renew,off,relay,relay-off}}` ([remote-access.md](remote-access.md)), `matrix {start,stop,status,add-user,push,remove}` (the private homeserver behind `ragon chat`; unrelated to `ragon-admin chat`), `desktop {install,run,build,status}`, `model {list,download}`, `adapter {list,install,remove,verify}` (LoRA adapters on the served model, node only; specs/DREAMFERENCE_RAGON_ADAPTERS.md), `monitor {status}` (`status [--json]` forwards to `ragon-node-monitor`, the node's health; the session monitor stays `ragon monitor`; specs/DREAMFERENCE_MONITORING.md), `main-model {set,inspect}`, `diffusion-model {set}` (absent while diffusion is switched off), `clear {model-cache,tensorize-cache}` (and the older `clear-tensorize-cache`, the same as `clear tensorize-cache`). Every command rejects unknown arguments.

## Sidecars behind `ragon web` and the app

Image search is `ragon-admin images start` (sidecar on `dreamference-sidecars`) and the `image_search` tool (`ragon-admin images mcp`, declared by the launcher's `ragon-rs/src/images.rs` on a node with image search set up, never at a configured `/airgapped on`); `ragon web` and the app serve `/images/<id>.jpg`. Voice is `ragon-admin voice start` (speaches, `127.0.0.1:8100`), behind `ragon web`'s `/api/transcribe` and the app's `voice/transcribe`. `server start` on a node starts both and the Google service when absent, a failure only a warning.
