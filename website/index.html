A coding helper that runs on your own machine.

Ragon is a coding helper, a chat assistant and a desktop app, and all of it runs on your own GB10. Nothing is sent to a cloud. There is no account, no bill for each use, and no tracking.

Install

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # downloads the model once (~20 GB), then starts it
$ cd ~/your-project && ragon    # that's all

This works on the NVIDIA DGX Spark and on every other GB10 machine. The script checks each download against the release's checksums, and shows you each sudo command before it runs it. You can read the script first.

Mac and Linux clients

Your other computers borrow the GB10's model over your home or office network. On a Mac or another Linux machine, the same command installs ragon, the part you type into. It finds the GB10 by itself.

Windows client preview

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

Type this in PowerShell. It needs no administrator rights. Windows then asks you once to set up a walled-off place where the helper runs commands. The installer is not signed yet, so Smart App Control must be off. Read the script.

Other ways to install

The release page also has the Mac disk image (Ragon-<version>-arm64-preview.dmg, or x64 for Intel) and the Windows installer (Ragon-Setup-<version>-x64.exe, or arm64). They are unsigned previews, so when you download them in a browser, your system stops them the first time. Before you open one, check it against the release's signed SHA256SUMS file.

  • macOS 15 and later: drag Ragon to Applications and open it once. Then go to System Settings › Privacy & Security and press Open Anyway. On macOS 14 and earlier, Control-click the app and choose Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control must be off.

Try these first

Or leave work for tonight with /night add <task>. Ragon goes through the list while you sleep, each task on its own git branch, and you look over the branches in the morning.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

🧭 A code index

A list of where things are defined and who uses them across your project, so the helper can look code up and not search for it by guessing.

🔎 Web search and page fetch

Search goes through a private SearXNG on your own machine, so there is no search account and no key to get. The questions still go out to the web to be answered.

🌙 Night Shift

Type /night add <task> before bed. By morning each task is done on its own git branch. Nothing is merged or pushed unless you do it.

What you get

The desktop app puts both ways of using Ragon in one window: Ask, where you put questions, and Work, where the helper edits your code. Work has a box to type tasks in (you can attach files, skills and commands), a pane to look over changes before you keep or undo them, separate working copies of your code (worktrees), terminal tabs, and a file tree beside the conversation. On your other computers the app talks to your GB10, which it finds on your network.

macOS preview

The install command puts Ragon in Applications next to ragon, and you open it like any other app. It runs on Apple silicon and Intel, with macOS 12 or later. ragon update updates it.

Linux

On the GB10, the file ragon_<version>_arm64.deb installs the app, its menu entry and the ragon-app command, along with the sandbox profile it needs. (A sandbox is a closed room for running commands, so they can't touch the rest of the machine.)

$ sudo apt install ./ragon_0.9.0_arm64.deb

Then open it from the application menu, or type ragon app. More.

Windows 11 preview

The PowerShell line installs the app too, for you alone and without administrator rights, with an entry in the Start menu. Settings → Apps removes it, and ragon update updates it. Smart App Control must be off.

ragon-admin mcp · ragon signal · ragon chat

JetBrains, VS Code, and your phone

You can connect JetBrains or VS Code through stdio MCP (ragon-admin mcp). You can also send messages to your GB10 from Signal (to yourself, in Note to Self), from Telegram (with the Mini App for working on repositories), and from Matrix over Tailscale. Every phone link is off until you turn it on. Signal is end-to-end encrypted, and Matrix runs on a server of your own. Telegram messages pass through Telegram's servers unencrypted, so use it only for things you would not mind sharing that way.

Your code stays on your desk, and you can check that it does

A cloud coding helper sends your source code to computers that belong to someone else. Ragon sends it nowhere. The model runs on your GB10, and nothing in Ragon calls home: no usage counts, no measurements, no sign-in, not even "anonymous" crash reports. So you can use it on code you are not allowed to upload, such as a client's work, protected data or a product not yet released.

One command runs a real Ragon session under strace, a tool that watches every call a program makes, and then lists each network connection the session opened:

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

All of it stayed on 127.0.0.1, which is the machine talking to itself. There was not one DNS lookup (a DNS lookup is asking the internet for the address of a name).

Want a firm guarantee?

Type /airgapped on. Every command the helper runs then gets an empty network from the Linux kernel. That is not a polite request to the model. There is simply no network to reach. At the same time, Full Access, which would get around the sandbox, is refused.

What can leave, and when

Only what you or the helper ask for: a web search (through a private SearXNG that runs on your own machine, though the search itself still goes out to the web), a fetch of a web page, a read-only request to a Google account you have connected, or a check for updates. With /airgapped on, none of these happens.

FAQ

Do I need a GB10?

Yes, to run the model. Your other computers are clients that borrow it: Linux (Arm or x86) and macOS with the same install command, and Windows (Arm or x86, preview) with the PowerShell line.

Does it really cost nothing?

Nothing for the program or for the model. Ragon is open source under the AGPL, and the model's weights are free to use. You pay for the machine and the electricity it uses.

What do I need besides the machine?

The operating system it comes with (DGX OS 7, or Ubuntu 24.04 where NVIDIA offers it), Docker with the NVIDIA Container Toolkit, Python 3 and Git. On plain Ubuntu, ragon-admin host check tells you what is missing.

Does anything ever go out to the internet?

Only what you or the helper ask for, such as a web search (through a SearXNG that runs on your own machine) and the downloads on first use. With /airgapped on, all of it is off.

Which model does it run?

Qwen3.8-27B, in NVIDIA's 4-bit format called NVFP4, served by our own engine, ragon-serve, with a small guessing helper called a DFlash2 drafter; SGLang stays as the fallback through 0.9.x. We chose and tuned all of it for the GB10. The weights take about 20 GB, and while it runs, about 38 GB of the machine's memory stays free.
