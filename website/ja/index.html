インストール

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # モデルは初回に 1 度だけダウンロードし（約 20 GB）、その後は配信します
$ cd ~/your-project && ragon    # これだけです

NVIDIA DGX Spark とすべての GB10 マシンで動作します。スクリプトは各ダウンロードをリリースのチェックサムで検証し、sudo コマンドは実行前に毎回表示します。気になる方は、先にスクリプトを読むこともできます。

Mac と Linux のクライアント

ほかのコンピュータは、ローカルネットワーク越しに GB10 のモデルを使います。Mac や別の Linux マシンでも、上と同じコマンドで ragon クライアントがインストールされ、GB10 は自動的に見つかります。

Windows クライアント プレビュー

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

PowerShell で実行します。管理者権限なしでインストールでき、そのあと Windows がエージェントのサンドボックスを設定するかどうか 1 度だけ確認します。まだ署名されていないため、スマート アプリ コントロール（Smart App Control）をオフにしておく必要があります。スクリプトを読む。

そのほかのインストール方法

リリースページには、Mac 用の dmg（Ragon-<version>-arm64-preview.dmg、Intel は x64）と、Windows 用インストーラ（Ragon-Setup-<version>-x64.exe、または arm64）もあります。いずれも署名のないプレビュー版で、ブラウザでダウンロードすると初回はブロックされます。先にリリースの署名付き SHA256SUMS と照合してください。

  • macOS 15 以降：Ragon を「アプリケーション」にドラッグして 1 度開き、システム設定 › プライバシーとセキュリティ › このまま開く を選びます。macOS 14 以前では、アプリを Control キーを押しながらクリック › 開く。
  • Windows:SmartScreen › 詳細情報 › 実行。スマート アプリ コントロール（Smart App Control）はオフにしておく必要があります。

まずはこれを試してみてください

あるいは /night add <task> で今夜の作業をキューに入れておきます。寝ている間に Ragon がキューを順にこなし、各タスクはそれぞれ専用の git ブランチに作られます。朝のコーヒーを飲みながらブランチをレビューするだけです。

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

自分のマシン上のプライベートな SearXNG を経由します。検索アカウントも API キーも不要です。

🌙 Night Shift

寝る前に /night add <task>。朝には各タスクがそれぞれの git ブランチに仕上がっています。あなたの了承なしにマージもプッシュもされません。

できること

Ragon のデスクトップアプリは、Ask と Work を 1 つのウィンドウにまとめました。Work はエージェントセッションのための本格的な作業台です。ファイル、スキル、コマンドを扱えるコンポーザー、ステージ・取り消し・コミットができるレビューペイン、ワークツリー、ターミナルタブ、スレッドの横にあるファイルツリーとファイルタブを備えています。ほかのコンピュータでは GB10 のクライアントとして動作し、GB10 はローカルネットワーク上で自動的に見つかります。

🪟 デスクトップアプリ プレビュー

Ask と Work が 1 つのウィンドウに。GB10、Mac、Linux、Windows で使えます。承認付きのエージェントセッション、レビューペイン、ワークツリー、元に戻す機能を備えています。

Web 検索、画像検索、音声入力を使った質問と、エージェントのセッションを、このマシンやペアリングしたスマートフォンから、同じローカルモデルで利用できます。

macOS プレビュー

インストールコマンドが ragon と並べて Ragon を「アプリケーション」に入れ、ほかのアプリと同じように開けます。Apple シリコンと Intel の両方、macOS 12 以降に対応。更新は ragon update で行います。

Linux

GB10 では、ragon_<version>_arm64.deb がアプリ本体、ランチャーのエントリ、ragon-app コマンド、そして必要なサンドボックスのプロファイルをインストールします：

$ sudo apt install ./ragon_0.9.0_arm64.deb

そのあとはアプリケーションメニューから、または ragon app で開きます。詳細。

Windows 11 プレビュー

PowerShell の 1 行でアプリも一緒にインストールされます。自分のユーザー専用で管理者権限は不要、スタートメニューにも登録されます。削除は「設定 → アプリ」から、更新は ragon update です。スマート アプリ コントロール（Smart App Control）はオフにしておく必要があります。

ragon-admin mcp · ragon signal · ragon chat

JetBrains、VS Code、そしてスマートフォン

読み取り専用で、サインイン情報はあなたのマシンから出ません。/airgapped on では完全にオフになります。

コードは手元から出ません。しかも、それを自分で確かめられます

クラウドのコーディングエージェントは、ソースコードを他人のサーバーに送ります。Ragon はどこにも送りません。モデルはあなたの GB10 で動き、Ragon の中に外へ通信するものは何もありません。利用状況の分析も、メトリクスも、サインインも、「匿名」のクラッシュレポートもありません。だから、アップロードが許されないコードにも使えます。顧客の案件、規制対象のデータ、未発表の製品などです。

コマンド 1 つで、実際の Ragon セッションを strace の下で実行し、確立されたすべてのネットワーク接続を一覧にします：

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

すべて 127.0.0.1 の中で完結しました。DNS の問い合わせは 1 件もありません。

確実な保証が必要ですか？

/airgapped on と入力すると、エージェントが実行するすべてのコマンドに、Linux カーネルから空のネットワーク名前空間が割り当てられます。モデルへのお願いではありません。到達できるネットワークがそもそも存在しないのです。サンドボックスを回避してしまう Full Access も、同時に拒否されます。

外に出るもの、そのタイミング

あなたまたはエージェントが求めたものだけです。Web 検索（自分のマシン上のプライベートな SearXNG 経由）、ページの取得、連携した Google アカウントへの読み取り専用リクエスト、更新の確認。/airgapped on では、そのどれも出ません。

Ragon を選ぶ理由

🔒 機密性

モデルも、コードも、プロンプトも、回答も、それがあるマシンの外には出ません。

  • アカウントなし、テレメトリなし
  • 何度でも再実行できるエグレス監査
  • /airgapped on はカーネルが強制

⚡ 速くて、請求なし

コンテキスト262K

✨ 設定は不要

  • チューニング不要：モデル、コンテキスト、カーネル、投機的デコーディングは GB10 向けに選定済みです。
  • マシンをフリーズさせません：ホストを事前に確認し、ロード中はメモリ負荷を監視します。
  • ほかのマシンから見つかります。同じローカルネットワーク上にあれば自動的に。
  • 更新はコマンド 1 つ：ragon update。

FAQ

GB10 は必須ですか？

モデルを動かすには必要です。ほかのコンピュータはクライアントとしてそれを使います。Linux（Arm または x86）と macOS は同じインストールコマンドで、Windows（Arm または x86、プレビュー）はPowerShell の 1 行で使えます。

本当に無料ですか？

はい。Ragon は AGPL のオープンソースで、モデルの重みも無料です。かかる費用は電気代だけです。

マシン以外に必要なものは？

付属の OS（DGX OS 7、ベンダーが提供している場合は Ubuntu 24.04）、NVIDIA Container Toolkit 入りの Docker、Python 3、Git です。素の Ubuntu では、ragon-admin host check が足りないものを教えてくれます。

インターネットに出ていくものはありますか？

あなたまたはエージェントが求めたものだけです。たとえば自分のマシン上の SearXNG 経由の Web 検索や、初回のダウンロードがそうです。/airgapped on にすると、そのすべてが止まります。

どのモデルが動きますか？

NVIDIA の 4 ビット NVFP4 形式の Qwen3.8-27B を、DFlash2 ドラフターを組み合わせた自社エンジン ragon-serve で配信します（0.9.x の間は SGLang がフォールバックとして残ります）。GB10 向けに選定・チューニングしたものです。重みは約 20 GB で、配信中もマシンのメモリは約 38 GB 空いたままです。

コードは手元に置いておこう

コードは書かれた机の上にとどまるべきだと思うなら、リポジトリにスターをお願いします。ほかの GB10 オーナーが Ragon を見つける手がかりになります。
