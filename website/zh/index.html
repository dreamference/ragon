安装

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # 模型只下载一次（约 20 GB），随后即开始提供服务
$ cd ~/your-project && ragon    # 就这么简单

适用于 NVIDIA DGX Spark 和所有 GB10 机器。脚本会对照发布版的校验和验证每个下载，并在运行每条 sudo 命令之前先打印出来。想看的话，可以先读一下脚本。

Mac 和 Linux 客户端

你的其他电脑通过本地网络使用 GB10 上的模型。在 Mac 或另一台 Linux 机器上，运行上面同一条命令即可安装 ragon 客户端，它会自动找到 GB10。

Windows 客户端 预览

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

在 PowerShell 中运行。无需管理员权限即可安装，之后 Windows 会询问一次，以设置智能体的沙箱。尚未签名，因此必须关闭智能应用控制（Smart App Control）。阅读脚本。

其他安装方式

发布页还提供 Mac 的 dmg（Ragon-<version>-arm64-preview.dmg,Intel 用 x64）和 Windows 安装程序（Ragon-Setup-<version>-x64.exe,或 arm64）。它们是未签名的预览版：用浏览器下载后，首次打开会被拦截。请先对照发布版已签名的 SHA256SUMS 逐一校验。

  • macOS 15 及更高版本：把 Ragon 拖到“应用程序”并打开一次，然后进入 系统设置 › 隐私与安全性 › 仍要打开。在 macOS 14 及更早版本上，按住 Control 点按该应用 › 打开。
  • Windows:SmartScreen › 更多信息 › 仍要运行。必须关闭智能应用控制（Smart App Control）。

先试试这些

或者用 /night add <task> 把任务排进今晚的队列：Ragon 在你睡觉时逐个处理，每个任务在各自的 git 分支上完成，你喝着咖啡审阅这些分支就行。

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

你能得到什么

Ragon 的桌面应用把 Ask 和 Work 放在同一个窗口里。Work 是一个完整的智能体会话工作台：带文件、技能和命令的输入框，可暂存、还原和提交的审阅面板，工作树，终端标签页，以及对话旁边的文件树和文件标签页。在你的其他电脑上，它是 GB10 的客户端，会在本地网络中自动找到 GB10。

你的代码不会离开你的桌面，而且你可以自己验证

云端编程智能体会把你的源代码发送到别人的服务器。Ragon 哪儿也不发：模型运行在你的 GB10 上，Ragon 里没有任何东西会回传数据。没有使用统计，没有指标，没有登录，也没有“匿名”崩溃报告。因此它可以用于你无权上传的代码：客户项目、受监管的数据、未发布的产品。

一条命令就能在 strace 下运行一次真实的 Ragon 会话，并列出它建立的每一个网络连接：

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

一切都留在 127.0.0.1。没有一次 DNS 查询。

需要硬性保证？

输入 /airgapped on,智能体运行的每条命令都会由 Linux 内核分配一个空的网络命名空间。这不是对模型的客气请求：根本就没有网络可连。同时，会绕过沙箱的 Full Access 也会被拒绝。

哪些会外发，何时外发

只有你或智能体要求的：网页搜索（经由你自己机器上的私有 SearXNG）、抓取网页、对你已连接的 Google 账号的只读请求，或检查更新。在 /airgapped on 下，这些全都不会发生。

常见问题

我必须有 GB10 吗？

运行模型需要。你的其他电脑则作为客户端使用它：Linux（Arm 或 x86）和 macOS 用同一条安装命令，Windows（Arm 或 x86，预览版）用那一行 PowerShell 命令。

真的免费吗？

是的。Ragon 以 AGPL 开源，模型权重也是免费的。你唯一的运行成本是电费。

除了这台机器，我还需要什么？

它自带的操作系统（DGX OS 7，或厂商提供时的 Ubuntu 24.04）、装有 NVIDIA Container Toolkit 的 Docker、Python 3 和 Git。在普通 Ubuntu 上，ragon-admin host check 会告诉你缺什么。

会有东西连到互联网吗？

只有你或智能体要求的内容，例如经由你自己机器上的 SearXNG 进行的网页搜索，以及首次下载。/airgapped on 会把这一切全部关闭。

它运行哪个模型？

NVIDIA 4 位 NVFP4 格式的 Qwen3.8-27B，由我们的引擎 ragon-serve 搭配 DFlash2 草稿模型提供服务（整个 0.9.x 期间 SGLang 仍作为备用），专为 GB10 选定并调优。权重约 20 GB；服务期间机器内存仍有约 38 GB 空闲。

让你的代码留在你的桌面上

如果你也认为代码应该留在写下它的那张桌子上，请给仓库点个星：其他 GB10 用户就是这样发现 Ragon 的。
