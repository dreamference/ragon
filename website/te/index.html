ఇన్‌స్టాల్

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # మోడల్‌ను ఒక్కసారి డౌన్‌లోడ్ చేస్తుంది (~20 GB), తర్వాత సర్వ్ చేస్తుంది
$ cd ~/your-project && ragon    # అంతే

NVIDIA DGX Spark మీద, అన్ని GB10 మెషీన్ల మీద పనిచేస్తుంది. స్క్రిప్ట్ ప్రతి డౌన్‌లోడ్‌ను రిలీజ్ చెక్‌సమ్‌లతో సరిచూస్తుంది, ప్రతి sudo కమాండ్‌ను నడిపే ముందు చూపిస్తుంది. కావాలంటే ముందు దాన్ని చదవండి.

Mac, Linux క్లయింట్లు

మీ ఇతర కంప్యూటర్లు లోకల్ నెట్‌వర్క్ ద్వారా GB10 మోడల్‌ను వాడుకుంటాయి. Mac లేదా మరో Linux మెషీన్‌లో పైన ఉన్న అదే కమాండ్ ragon క్లయింట్‌ను ఇన్‌స్టాల్ చేస్తుంది; అది GB10 ను తనంతట తానే కనుగొంటుంది.

Windows క్లయింట్ ప్రివ్యూ

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

PowerShell లో. అడ్మినిస్ట్రేటర్ హక్కులు లేకుండా ఇన్‌స్టాల్ అవుతుంది, తర్వాత ఏజెంట్ శాండ్‌బాక్స్ సెటప్ కోసం Windows ఒక్కసారి అడుగుతుంది. ఇంకా సైన్ చేయలేదు, కాబట్టి Smart App Control ఆఫ్‌లో ఉండాలి. స్క్రిప్ట్ చదవండి.

ఇన్‌స్టాల్ చేయడానికి ఇతర మార్గాలు

రిలీజ్ పేజీలో Mac dmg (Ragon-<version>-arm64-preview.dmg, Intel కోసం x64), Windows ఇన్‌స్టాలర్ (Ragon-Setup-<version>-x64.exe, లేదా arm64) కూడా ఉంటాయి. ఇవి సైన్ చేయని ప్రివ్యూలు: బ్రౌజర్‌లో డౌన్‌లోడ్ చేస్తే మొదటిసారి ఆపేస్తాయి. ముందు ప్రతిదాన్ని రిలీజ్ సైన్ చేసిన SHA256SUMS తో సరిచూడండి.

  • macOS 15 మరియు తర్వాత: Ragon ను Applications లోకి లాగి ఒకసారి తెరవండి, తర్వాత System Settings › Privacy & Security › Open Anyway. macOS 14 మరియు అంతకు ముందు: యాప్ మీద Control-క్లిక్ › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control ఆఫ్‌లో ఉండాలి.

ముందు వీటిని ప్రయత్నించండి

లేదా ఈ రాత్రికి పనిని క్యూలో పెట్టండి: /night add <task>. మీరు నిద్రపోయే సమయంలో Ragon క్యూను పూర్తి చేస్తుంది, ప్రతి టాస్క్ దాని సొంత git బ్రాంచ్‌లో, ఉదయం కాఫీ తాగుతూ బ్రాంచ్‌లను సమీక్షించండి.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

macOS ప్రివ్యూ

ఇన్‌స్టాల్ కమాండ్ Ragon ను ragon పక్కనే Applications లో ఉంచుతుంది, ఇతర యాప్‌ల్లాగే తెరుచుకుంటుంది. Apple silicon, Intel, macOS 12 లేదా ఆ తర్వాత. ragon update దాన్ని అప్‌డేట్ చేస్తుంది.

Linux

GB10 మీద ragon_<version>_arm64.deb యాప్‌ను, దాని లాంచర్ ఎంట్రీని, ragon-app కమాండ్‌ను, అవసరమైన శాండ్‌బాక్స్ ప్రొఫైల్‌తో సహా ఇన్‌స్టాల్ చేస్తుంది:

$ sudo apt install ./ragon_0.9.0_arm64.deb

తర్వాత అప్లికేషన్ మెనూ నుండి లేదా ragon app తో తెరవండి. మరింత.

Windows 11 ప్రివ్యూ

PowerShell లైన్ యాప్‌ను కూడా ఇన్‌స్టాల్ చేస్తుంది, మీకు మాత్రమే, అడ్మినిస్ట్రేటర్ హక్కులు లేకుండా, Start మెనూ ఎంట్రీతో; Settings → Apps నుండి తొలగించవచ్చు; ragon update అప్‌డేట్ చేస్తుంది. Smart App Control ఆఫ్‌లో ఉండాలి.

ragon-admin mcp · ragon signal · ragon chat

JetBrains, VS Code మరియు మీ ఫోన్

stdio MCP (ragon-admin mcp) ద్వారా JetBrains లేదా VS Code ని కనెక్ట్ చేయండి, లేదా Signal (Note to Self), Telegram (Mini App రిపోజిటరీ వర్క్‌బెంచ్‌తో) మరియు Tailscale పై Matrix నుండి మీ GB10 కి సందేశం పంపండి. మీరు ఆన్ చేసే వరకు ప్రతి ఫోన్ బ్రిడ్జ్ ఆఫ్‌లోనే ఉంటుంది.

డాక్స్ →
$ ragon-admin mcp            # stdio MCP for JetBrains and VS Code
$ ragon signal setup         # Note to Self only, off until linked

చదవడానికి మాత్రమే, మీ మెషీన్‌లోనే ఉండే సైన్-ఇన్ ద్వారా. /airgapped on లో పూర్తిగా ఆఫ్.

మీ కోడ్ మీ డెస్క్ దాటదు, అది మీరు నిరూపించవచ్చు

క్లౌడ్ కోడింగ్ ఏజెంట్లు మీ సోర్స్ కోడ్‌ను ఇతరుల సర్వర్లకు పంపుతాయి. Ragon దాన్ని ఎక్కడికీ పంపదు: మోడల్ మీ GB10 మీదే నడుస్తుంది, Ragon లో ఏదీ బయటికి సంప్రదించదు. వినియోగ విశ్లేషణలు, మెట్రిక్స్, సైన్-ఇన్, “అనామక” క్రాష్ రిపోర్టులు ఏవీ లేవు. అందువల్ల అప్‌లోడ్ చేయడానికి అనుమతి లేని కోడ్‌కు ఇది వాడదగినది: క్లయింట్ పని, నియంత్రిత డేటా, విడుదల కాని ఉత్పత్తులు.

ఒక కమాండ్ నిజమైన Ragon సెషన్‌ను strace కింద నడిపి, అది చేసిన ప్రతి నెట్‌వర్క్ కనెక్షన్‌ను జాబితా చేస్తుంది:

$ ragon-admin audit egress

   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

అంతా 127.0.0.1 లోనే ఉంది. ఒక్క DNS లుకప్ కూడా లేదు.

కచ్చితమైన హామీ కావాలా?

/airgapped on అని టైప్ చేయండి; ఏజెంట్ నడిపే ప్రతి కమాండ్‌కు Linux కెర్నెల్ ఖాళీ నెట్‌వర్క్ నేమ్‌స్పేస్ ఇస్తుంది. ఇది మోడల్‌ను మర్యాదగా అడగడం కాదు: చేరుకోవడానికి నెట్‌వర్క్ అసలే ఉండదు. శాండ్‌బాక్స్‌ను దాటవేసే Full Access అదే సమయంలో తిరస్కరించబడుతుంది.

ఏమి బయటికి వెళ్లవచ్చు, ఎప్పుడు

మీరు లేదా ఏజెంట్ అడిగినదే: వెబ్ సెర్చ్ (మీ సొంత మెషీన్‌లోని ప్రైవేట్ SearXNG ద్వారా), పేజీ ఫెచ్, మీరు కనెక్ట్ చేసిన Google ఖాతాకు చదవడానికి మాత్రమే అభ్యర్థన, లేదా అప్‌డేట్ తనిఖీ. /airgapped on లో వీటిలో ఏదీ లేదు.

ప్రశ్నలు

నాకు GB10 కావాలా?

అవును, మోడల్ నడపడానికి. మీ ఇతర కంప్యూటర్లు దాన్ని క్లయింట్లుగా వాడుతాయి: Linux (Arm లేదా x86), macOS అదే ఇన్‌స్టాల్ కమాండ్‌తో, Windows (Arm లేదా x86, ప్రివ్యూ) PowerShell లైన్ తో.

ఇది నిజంగా ఉచితమేనా?

అవును. Ragon AGPL కింద ఓపెన్ సోర్స్, మోడల్ వెయిట్‌లు ఉచితం. మీకు అయ్యే నిర్వహణ ఖర్చు కరెంటు మాత్రమే.

మెషీన్ కాకుండా నాకు ఇంకా ఏమి కావాలి?

దానితో వచ్చే OS (DGX OS 7, లేదా విక్రేత ఇచ్చే చోట Ubuntu 24.04), NVIDIA Container Toolkit తో Docker, Python 3, Git. సాధారణ Ubuntu లో ragon-admin host check ఏమి లేదో చెబుతుంది.

ఏదైనా ఎప్పుడైనా ఇంటర్నెట్‌కు చేరుతుందా?

మీరు లేదా ఏజెంట్ అడిగినదే, ఉదాహరణకు మీ సొంత మెషీన్‌లోని SearXNG ద్వారా వెబ్ సెర్చ్, మొదటిసారి డౌన్‌లోడ్‌లు. /airgapped on వాటన్నిటినీ ఆపేస్తుంది.

ఇది ఏ మోడల్ నడుపుతుంది?

NVIDIA 4-బిట్ NVFP4 ఫార్మాట్‌లో Qwen3.8-27B, DFlash2 డ్రాఫ్టర్‌తో మా ఇంజిన్ ragon-serve ద్వారా సర్వ్ అవుతుంది (0.9.x అంతటా SGLang ఫాల్‌బ్యాక్‌గా ఉంటుంది), GB10 కోసం ఎంచుకుని ట్యూన్ చేసినది. వెయిట్‌లు సుమారు 20 GB; సర్వ్ చేస్తున్నప్పుడు మెషీన్ మెమరీలో సుమారు 38 GB ఖాళీగా ఉంటుంది.

మీ కోడ్‌ను మీ డెస్క్ మీదే ఉంచండి

కోడ్ రాసిన డెస్క్ మీదే ఉండాలని మీరు నమ్మితే, రిపాజిటరీకి స్టార్ ఇవ్వండి: అలా ఇతర GB10 యజమానులు Ragon ను కనుగొంటారు.
