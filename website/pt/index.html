Instalar

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # baixa o modelo uma única vez (~20 GB) e depois o serve
$ cd ~/your-project && ragon    # só isso

Funciona no NVIDIA DGX Spark e em toda máquina GB10. O script confere cada download com os checksums da versão e mostra cada comando sudo antes de executá-lo. Leia-o antes, se quiser.

Clientes para Mac e Linux

Seus outros computadores usam o modelo do GB10 pela rede local. Em um Mac ou em outra máquina Linux, o mesmo comando acima instala o cliente ragon, que encontra o GB10 sozinho.

Cliente para Windows preview

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

No PowerShell. Instala sem direitos de administrador e depois o Windows pede uma vez para configurar o sandbox do agente. Ainda sem assinatura, então o Smart App Control precisa estar desativado. Leia o script.

Outras formas de instalar

A página da versão traz também o dmg para Mac (Ragon-<version>-arm64-preview.dmg, ou x64 para Intel) e o instalador do Windows (Ragon-Setup-<version>-x64.exe, ou arm64). São previews sem assinatura: baixados pelo navegador, são bloqueados na primeira vez. Confira cada um com o SHA256SUMS assinado da versão antes.

  • macOS 15 e posterior: arraste o Ragon para Aplicativos e abra-o uma vez; depois, Ajustes do Sistema › Privacidade e Segurança › Abrir Mesmo Assim. No macOS 14 e anteriores, Control-clique no app › Abrir.
  • Windows: SmartScreen › Mais informações › Executar assim mesmo. O Smart App Control precisa estar desativado.

Experimente isto primeiro

Ou deixe trabalho na fila para esta noite com /night add <task>: o Ragon percorre a fila enquanto você dorme, cada tarefa em seu próprio branch do git, e você revisa os branches com o café.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Seu código não sai da sua mesa — e você pode provar

Agentes de programação na nuvem enviam seu código-fonte para os servidores de outra empresa. O Ragon não o envia para lugar nenhum: o modelo roda no seu GB10 e nada no Ragon liga para casa. Sem análise de uso, sem métricas, sem login, sem relatórios de falha “anônimos”. Isso o torna utilizável com código que você não pode enviar: trabalho de clientes, dados regulados, produtos não lançados.

Um comando roda uma sessão real do Ragon sob o strace e lista cada conexão de rede que ela fez:

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Tudo ficou em 127.0.0.1. Nenhuma consulta DNS.

Precisa de uma garantia firme?

Digite /airgapped on e cada comando que o agente executa recebe do kernel do Linux um namespace de rede vazio. Não é um pedido educado ao modelo: simplesmente não há rede para alcançar. O Full Access, que contornaria o sandbox, é recusado ao mesmo tempo.

O que pode sair, e quando

Só o que você ou o agente pedirem: uma busca na web (por um SearXNG privado na sua própria máquina), o download de uma página, uma requisição somente leitura a uma conta Google que você conectou, ou uma verificação de atualização. Com /airgapped on, nada disso.

FAQ

Preciso de um GB10?

Sim, para rodar o modelo. Seus outros computadores o usam como clientes: Linux (Arm ou x86) e macOS com o mesmo comando de instalação, Windows (Arm ou x86, preview) com a linha do PowerShell.

É grátis de verdade?

Sim. O Ragon é código aberto sob a AGPL, e os pesos do modelo são gratuitos. Seu único custo de operação é a eletricidade.

O que preciso além da máquina?

O sistema operacional que ela traz (DGX OS 7, ou Ubuntu 24.04 onde o fabricante o oferece), Docker com o NVIDIA Container Toolkit, Python 3 e Git. Em um Ubuntu comum, ragon-admin host check diz o que está faltando.

Alguma coisa chega à internet?

Só o que você ou o agente pedirem, como uma busca na web por um SearXNG na sua própria máquina, e os downloads da primeira vez. /airgapped on desliga tudo isso.

Qual modelo ele roda?

Qwen3.8-27B no formato NVFP4 de 4 bits da NVIDIA, servido pelo nosso motor ragon-serve com um drafter DFlash2 (o SGLang continua como alternativa em toda a 0.9.x), escolhido e ajustado para o GB10. Cerca de 20 GB de pesos; aproximadamente 38 GB da memória da máquina continuam livres enquanto ele serve.
