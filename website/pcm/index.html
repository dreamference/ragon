Install

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # e go download di model once (~20 GB), then e go start serve am
$ cd ~/your-project && ragon    # na so e be

E dey work for NVIDIA DGX Spark and every GB10 machine. Di script dey check every download against di release checksums and e dey show every sudo command before e run am. Read am first if you want.

Mac and Linux clients

Your oda computers dey use di GB10 model through di local network. For Mac or any oda Linux machine, di same command wey dey up go install di ragon client; e go find di GB10 by itself.

Windows client preview

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

Oda ways to install

Di release page get di Mac dmg too (Ragon-<version>-arm64-preview.dmg, or x64 for Intel) and di Windows installer (Ragon-Setup-<version>-x64.exe, or arm64). Dem be unsigned previews: if you download dem with browser, dem go block dem di first time. Check each one against di release signed SHA256SUMS first.

  • macOS 15 and newer: drag Ragon go Applications and open am once, then System Settings › Privacy & Security › Open Anyway. For macOS 14 and older, Control-click di app › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control must dey off.

Try dis ones first

Or put work for tonight queue with /night add <task>: Ragon go work through di queue while you dey sleep, each task for im own git branch, and you go review di branches with coffee for hand.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Your code no dey leave your table — and you fit prove am

Cloud coding agents dey send your source code go anoda person servers. Ragon no dey send am anywhere: di model dey run for your GB10, and nothing inside Ragon dey phone home. No usage analytics, no metrics, no sign-in, no "anonymous" crash reports. Dat one make e fit work for code wey dem no allow you upload: client work, regulated data, unreleased products.

One command dey run real Ragon session under strace and list every network connection wey e make:

You need sure guarantee?

Type /airgapped on and every command wey di agent run go get empty network namespace from di Linux kernel. E no be polite request to di model: network just no dey to reach. Full Access, wey for bypass di sandbox, dem go refuse am at di same time.

Wetin fit comot, and when

Only wetin you or di agent ask for: web search (through private SearXNG for your own machine), page fetch, read-only request to Google account wey you connect, or update check. For /airgapped on, none of dem.

FAQ

I need GB10?

Yes, to run di model. Your oda computers dey use am as clients: Linux (Arm or x86) and macOS with di same install command, Windows (Arm or x86, preview) with di PowerShell line.

E really free?

Yes. Ragon na open source under di AGPL, and di model weights free. Di only running cost wey you get na electricity.

Wetin I need apart from di machine?

Di OS wey e come with (DGX OS 7, or Ubuntu 24.04 where di vendor offer am), Docker with di NVIDIA Container Toolkit, Python 3 and Git. For plain Ubuntu, ragon-admin host check go tell you wetin dey miss.

Anything dey ever reach internet?

Only wetin you or di agent ask for, like web search through SearXNG for your own machine, and di first-time downloads. /airgapped on dey turn all of am off.

Which model e dey run?

Qwen3.8-27B for NVIDIA 4-bit NVFP4 format, wey our own engine ragon-serve dey serve with DFlash2 drafter (SGLang remain as fallback for all of 0.9.x), dem choose and tune am for di GB10. About 20 GB of weights; roughly 38 GB of di machine memory go remain free while e dey serve.
