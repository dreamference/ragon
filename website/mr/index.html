इन्स्टॉल

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # मॉडेल एकदाच डाउनलोड होते (~20 GB), मग सुरू होते
$ cd ~/your-project && ragon    # झाले, एवढेच

NVIDIA DGX Spark आणि प्रत्येक GB10 मशीनवर चालते. स्क्रिप्ट प्रत्येक डाउनलोड रिलीझच्या चेकसमशी पडताळते आणि प्रत्येक sudo कमांड चालवण्यापूर्वी ती दाखवते. हवे असल्यास आधी ती वाचा.

Mac आणि Linux क्लायंट

तुमचे इतर कॉम्प्युटर लोकल नेटवर्कवरून GB10 चे मॉडेल वापरतात. Mac किंवा दुसऱ्या Linux मशीनवर वरचीच कमांड ragon क्लायंट इन्स्टॉल करते; तो GB10 स्वतःहून शोधतो.

Windows क्लायंट प्रिव्ह्यू

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

PowerShell मध्ये. प्रशासक अधिकारांशिवाय इन्स्टॉल होते, मग Windows एकदा एजंटचा सँडबॉक्स सेट करायला सांगते. अजून साइन केलेले नाही, म्हणून Smart App Control बंद असायला हवे. स्क्रिप्ट वाचा.

इन्स्टॉल करण्याचे इतर मार्ग

रिलीझ पेजवर Mac चे dmg (Ragon-<version>-arm64-preview.dmg, Intel साठी x64) आणि Windows इन्स्टॉलर (Ragon-Setup-<version>-x64.exe, किंवा arm64) देखील आहेत. हे साइन न केलेले प्रिव्ह्यू आहेत: ब्राउझरमधून डाउनलोड केल्यास पहिल्यांदा थांबवले जातात. आधी प्रत्येक फाइल रिलीझच्या साइन केलेल्या SHA256SUMS शी तपासा.

  • macOS 15 आणि नंतरचे: Ragon ला Applications मध्ये ओढा आणि एकदा उघडा, मग System Settings › Privacy & Security › Open Anyway. macOS 14 आणि जुन्यामध्ये ॲपवर Control-क्लिक करा › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control बंद असायला हवे.

आधी हे करून पहा

किंवा आज रात्रीसाठी काम रांगेत लावा: /night add <task>. तुम्ही झोपलेले असताना Ragon रांग संपवते, प्रत्येक टास्क स्वतःच्या git ब्रांचवर, आणि सकाळी चहा पिताना तुम्ही ब्रांच तपासता.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

macOS प्रिव्ह्यू

इन्स्टॉल कमांड Ragon ला ragon सोबत Applications मध्ये ठेवते, आणि ते इतर कोणत्याही ॲपप्रमाणे उघडते. Apple silicon आणि Intel, macOS 12 किंवा नंतरचे. ragon update ते अपडेट करते.

Linux

GB10 वर ragon_<version>_arm64.deb ॲप, त्याची लाँचर एंट्री आणि ragon-app कमांड इन्स्टॉल करते, सोबत त्याला लागणारा सँडबॉक्स प्रोफाइल:

$ sudo apt install ./ragon_0.9.0_arm64.deb

मग ते ॲप्लिकेशन मेनूमधून उघडा, किंवा ragon app ने. अधिक.

Windows 11 प्रिव्ह्यू

PowerShell ची ओळ ॲपही इन्स्टॉल करते, फक्त तुमच्यासाठी आणि प्रशासक अधिकारांशिवाय, Start मेनू एंट्रीसह; Settings → Apps मधून ते काढता येते; ragon update ते अपडेट करते. Smart App Control बंद असायला हवे.

ragon-admin mcp · ragon signal · ragon chat

JetBrains, VS Code आणि तुमचा फोन

stdio MCP (ragon-admin mcp) द्वारे JetBrains किंवा VS Code जोडा, किंवा Signal (Note to Self), Telegram (Mini App रिपॉझिटरी वर्कबेंचसह) आणि Tailscale वरील Matrix वरून तुमच्या GB10 ला संदेश पाठवा. तुम्ही चालू करेपर्यंत प्रत्येक फोन ब्रिज बंद राहतो.

डॉक्स →
$ ragon-admin mcp            # stdio MCP for JetBrains and VS Code
$ ragon signal setup         # Note to Self only, off until linked
$ ragon chat telegram setup  # topics and the Mini App

📬 Gmail, Drive, Calendar प्रिव्ह्यू

रीड-ओन्ली, तुमच्या मशीनवरच राहणाऱ्या साइन-इनमधून. /airgapped on वर पूर्णपणे बंद.

तुमचा कोड तुमच्या डेस्कबाहेर जात नाही, आणि तुम्ही ते सिद्ध करू शकता

क्लाउड कोडिंग एजंट तुमचा सोर्स कोड दुसऱ्याच्या सर्व्हरवर पाठवतात. Ragon तो कुठेही पाठवत नाही: मॉडेल तुमच्या GB10 वर चालते, आणि Ragon मधले काहीही बाहेर संपर्क साधत नाही. वापराचे विश्लेषण नाही, मेट्रिक्स नाहीत, साइन-इन नाही, "अनामिक" क्रॅश रिपोर्ट नाहीत. त्यामुळे अपलोड करण्याची परवानगी नसलेल्या कोडसाठी ते वापरता येते: क्लायंटचे काम, नियंत्रित डेटा, अप्रकाशित उत्पादने.

एक कमांड strace खाली खऱ्या Ragon सेशनला चालवते आणि त्याने केलेल्या प्रत्येक नेटवर्क कनेक्शनची यादी देते:

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

सगळे काही 127.0.0.1 वरच राहिले. एकही DNS लुकअप नाही.

पक्की हमी हवी?

/airgapped on लिहा, आणि एजंट चालवत असलेल्या प्रत्येक कमांडला Linux कर्नलकडून रिकामा नेटवर्क नेमस्पेस मिळतो. ही मॉडेलला केलेली नम्र विनंती नाही: पोहोचायला नेटवर्कच नाही. सँडबॉक्स टाळणारे Full Access त्याच वेळी नाकारले जाते.

FAQ

मला GB10 लागेल का?

हो, मॉडेल चालवण्यासाठी. तुमचे इतर कॉम्प्युटर त्याचे क्लायंट म्हणून चालतात: Linux (Arm किंवा x86) आणि macOS त्याच इन्स्टॉल कमांडने, Windows (Arm किंवा x86, प्रिव्ह्यू) PowerShell च्या ओळीने.

ते खरंच मोफत आहे का?

हो. Ragon AGPL अंतर्गत ओपन सोर्स आहे, आणि मॉडेलचे वेट्स मोफत आहेत. तुमचा एकमेव चालू खर्च वीज आहे.

मशीनशिवाय आणखी काय लागते?

त्यासोबत येणारी OS (DGX OS 7, किंवा जिथे विक्रेता देतो तिथे Ubuntu 24.04), NVIDIA Container Toolkit सह Docker, Python 3 आणि Git. साध्या Ubuntu वर ragon-admin host check काय कमी आहे ते सांगते.

काही कधी इंटरनेटपर्यंत पोहोचते का?

फक्त तुम्ही किंवा एजंट जे मागता तेच, जसे तुमच्या स्वतःच्या मशीनवरील SearXNG मार्फत वेब सर्च, आणि पहिल्यांदाचे डाउनलोड. /airgapped on हे सगळे बंद करते.

ते कोणते मॉडेल चालवते?

NVIDIA च्या 4-बिट NVFP4 फॉरमॅटमधील Qwen3.8-27B, आमच्या इंजिन ragon-serve वर DFlash2 ड्राफ्टरसह (संपूर्ण 0.9.x मध्ये SGLang फॉलबॅक म्हणून राहते), GB10 साठी निवडलेले आणि ट्यून केलेले. सुमारे 20 GB चे वेट्स; सर्व्ह करताना मशीनची सुमारे 38 GB मेमरी मोकळी राहते.

तुमचा कोड तुमच्या डेस्कवरच ठेवा

कोड ज्या डेस्कवर लिहिला गेला तिथेच राहिला पाहिजे असे तुम्हाला वाटत असेल, तर रिपॉझिटरीला स्टार द्या: अशा प्रकारे इतर GB10 मालकांना Ragon सापडते.
