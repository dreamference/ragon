Установка

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # один раз скачивает модель (~20 ГБ), затем запускает её
$ cd ~/your-project && ragon    # вот и всё

Работает на NVIDIA DGX Spark и на любой машине с GB10. Скрипт проверяет каждую загрузку по контрольным суммам релиза и показывает каждую команду sudo перед запуском. Сначала прочитайте его, если хотите.

Клиенты для Mac и Linux

Ваши остальные компьютеры используют модель GB10 по локальной сети. На Mac или другой Linux-машине та же команда выше ставит клиент ragon; он сам находит GB10.

Клиент для Windows превью

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

В PowerShell. Установка идёт без прав администратора, после чего Windows один раз спросит о настройке песочницы агента. Пока без подписи, поэтому Smart App Control должен быть выключен. Прочитать скрипт.

Другие способы установки

На странице релиза есть также dmg для Mac (Ragon-<version>-arm64-preview.dmg, для Intel x64) и установщик для Windows (Ragon-Setup-<version>-x64.exe, либо arm64). Это неподписанные превью: скачанные через браузер, они блокируются при первом запуске. Сначала сверьте каждый файл с подписанным файлом SHA256SUMS релиза.

  • macOS 15 и новее: перетащите Ragon в «Программы» и один раз откройте, затем «Системные настройки» › «Конфиденциальность и безопасность» › Всё равно открыть. В macOS 14 и старше: щёлкните по приложению с зажатым Control › «Открыть».
  • Windows: SmartScreen › Подробнее › Выполнить в любом случае. Smart App Control должен быть выключен.

Попробуйте сначала это

Или поставьте работу в очередь на ночь командой /night add <task>: Ragon разбирает очередь, пока вы спите, каждую задачу в своей git-ветке, а вы просматриваете ветки за утренним кофе.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Команда установки кладёт Ragon в «Программы» рядом с ragon, и оно открывается как любое другое приложение. Apple silicon и Intel, macOS 12 или новее. ragon update обновляет его.

Linux

На GB10 пакет ragon_<version>_arm64.deb ставит приложение, его запись в меню и команду ragon-app вместе с нужным профилем песочницы:

$ sudo apt install ./ragon_0.9.0_arm64.deb

Затем откройте его из меню приложений или командой ragon app. Подробнее.

Windows 11 превью

Строка PowerShell ставит и приложение: только для вас, без прав администратора, с записью в меню «Пуск»; удаляется через «Параметры → Приложения»; ragon update обновляет его. Smart App Control должен быть выключен.

Ваш код никогда не покидает ваш стол — и это можно доказать

Облачные кодинг-агенты отправляют ваш исходный код на чужие серверы. Ragon не отправляет его никуда: модель работает на вашем GB10, и ничто в Ragon не отправляет данные «домой». Ни аналитики использования, ни метрик, ни входа в аккаунт, ни «анонимных» отчётов о сбоях. Поэтому его можно использовать для кода, который нельзя выгружать: клиентских проектов, регулируемых данных, неизданных продуктов.

Одна команда запускает настоящую сессию Ragon под strace и перечисляет все сетевые соединения, которые она открыла:

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Всё осталось на 127.0.0.1. Ни одного DNS-запроса.

Нужна жёсткая гарантия?

Введите /airgapped on, и каждая команда, которую запускает агент, получает от ядра Linux пустое сетевое пространство имён. Это не вежливая просьба к модели: просто нет сети, до которой можно достучаться. Full Access, который обошёл бы песочницу, при этом отклоняется.

Что может уйти и когда

Только то, что запрашиваете вы или агент: веб-поиск (через приватный SearXNG на вашей машине), загрузка страницы, запрос только на чтение к подключённому аккаунту Google или проверка обновлений. При /airgapped on — ничего из этого.

FAQ

Нужен ли мне GB10?

Да, чтобы запускать модель. Остальные ваши компьютеры используют его как клиенты: Linux (Arm или x86) и macOS с той же командой установки, Windows (Arm или x86, превью) со строкой PowerShell.

Это правда бесплатно?

Да. Ragon — открытый исходный код под AGPL, а веса модели бесплатны. Единственные текущие расходы — электричество.

Что нужно, кроме самой машины?

Поставляемая с ней ОС (DGX OS 7 или Ubuntu 24.04, где её предлагает вендор), Docker с NVIDIA Container Toolkit, Python 3 и Git. На обычной Ubuntu ragon-admin host check подскажет, чего не хватает.

Уходит ли что-нибудь в интернет?

Только то, что запрашиваете вы или агент, например веб-поиск через SearXNG на вашей машине, и загрузки при первом запуске. /airgapped on отключает всё это.

Какую модель он запускает?

Qwen3.8-27B в 4-битном формате NVIDIA NVFP4, обслуживается нашим движком ragon-serve с драфтером DFlash2 (SGLang остаётся запасным вариантом на протяжении всей 0.9.x), выбрана и настроена под GB10. Около 20 ГБ весов; пока она работает, около 38 ГБ памяти машины остаются свободными.
