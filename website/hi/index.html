इंस्टॉल

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # मॉडल एक बार डाउनलोड होता है (~20 GB), फिर चालू हो जाता है
$ cd ~/your-project && ragon    # बस, इतना ही

NVIDIA DGX Spark और हर GB10 मशीन पर चलता है। स्क्रिप्ट हर डाउनलोड को रिलीज़ के चेकसम से जाँचती है और हर sudo कमांड चलाने से पहले उसे दिखा देती है। चाहें तो पहले उसे पढ़ लें।

Mac और Linux क्लाइंट

आपके बाकी कंप्यूटर लोकल नेटवर्क पर GB10 के मॉडल का इस्तेमाल करते हैं। Mac या किसी दूसरी Linux मशीन पर ऊपर वाली वही कमांड ragon क्लाइंट इंस्टॉल करती है; वह GB10 को खुद ढूँढ लेता है।

Windows क्लाइंट प्रीव्यू

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

PowerShell में। यह एडमिनिस्ट्रेटर अधिकार के बिना इंस्टॉल होता है, फिर Windows एक बार एजेंट का सैंडबॉक्स सेट करने को कहता है। अभी साइन नहीं किया गया है, इसलिए Smart App Control बंद होना चाहिए। स्क्रिप्ट पढ़ें।

इंस्टॉल करने के दूसरे तरीके

रिलीज़ पेज पर Mac का dmg (Ragon-<version>-arm64-preview.dmg, Intel के लिए x64) और Windows इंस्टॉलर (Ragon-Setup-<version>-x64.exe, या arm64) भी हैं। ये बिना साइन किए प्रीव्यू हैं: ब्राउज़र से डाउनलोड करने पर पहली बार रोक दिए जाते हैं। पहले हर एक को रिलीज़ की साइन की हुई SHA256SUMS से जाँच लें।

  • macOS 15 और बाद के संस्करण: Ragon को Applications में खींचें और एक बार खोलें, फिर System Settings › Privacy & Security › Open Anyway। macOS 14 और पुराने में ऐप पर Control-क्लिक करें › Open।
  • Windows: SmartScreen › More info › Run anyway। Smart App Control बंद होना चाहिए।

पहले ये आज़माएँ

या आज रात के लिए काम कतार में लगाएँ: /night add <task>। आपके सोते समय Ragon कतार निपटाता है, हर टास्क अपनी git ब्रांच पर, और सुबह चाय पर आप ब्रांच देख लेते हैं।

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

आपको क्या मिलता है

macOS प्रीव्यू

इंस्टॉल कमांड Ragon को ragon के साथ Applications में रख देती है, और यह किसी भी दूसरे ऐप की तरह खुलता है। Apple silicon और Intel, macOS 12 या उसके बाद। ragon update इसे अपडेट करता है।

Linux

GB10 पर ragon_<version>_arm64.deb ऐप, उसकी लॉन्चर एंट्री और ragon-app कमांड इंस्टॉल करता है, साथ में उसके लिए ज़रूरी सैंडबॉक्स प्रोफ़ाइल:

$ sudo apt install ./ragon_0.9.0_arm64.deb

फिर इसे एप्लिकेशन मेन्यू से खोलें, या ragon app से। और जानें।

Windows 11 प्रीव्यू

PowerShell की लाइन ऐप को भी इंस्टॉल कर देती है, सिर्फ़ आपके लिए और एडमिनिस्ट्रेटर अधिकार के बिना, Start मेन्यू एंट्री के साथ; Settings → Apps से इसे हटाया जा सकता है; ragon update इसे अपडेट करता है। Smart App Control बंद होना चाहिए।

आपका कोड आपकी डेस्क से बाहर नहीं जाता, और आप इसे साबित कर सकते हैं

क्लाउड कोडिंग एजेंट आपका सोर्स कोड किसी और के सर्वर पर भेजते हैं। Ragon उसे कहीं नहीं भेजता: मॉडल आपके GB10 पर चलता है, और Ragon में कुछ भी बाहर किसी सर्वर से संपर्क नहीं करता। कोई उपयोग विश्लेषण नहीं, कोई मेट्रिक्स नहीं, कोई साइन-इन नहीं, कोई "अनाम" क्रैश रिपोर्ट नहीं। इसलिए इसे उस कोड पर इस्तेमाल किया जा सकता है जिसे अपलोड करने की अनुमति नहीं: क्लाइंट का काम, नियंत्रित डेटा, अप्रकाशित उत्पाद।

एक कमांड strace के अंतर्गत असली Ragon सेशन चलाती है और उसके बनाए हर नेटवर्क कनेक्शन की सूची देती है:

$ ragon-admin audit egress

   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

सब कुछ 127.0.0.1 पर रहा। एक भी DNS लुकअप नहीं।

पक्की गारंटी चाहिए?

/airgapped on लिखें और एजेंट की चलाई हर कमांड को Linux कर्नेल से खाली नेटवर्क नेमस्पेस मिलता है। यह मॉडल से विनम्र अनुरोध नहीं है: पहुँचने के लिए नेटवर्क है ही नहीं। Full Access, जो सैंडबॉक्स को बायपास करता, उसी समय अस्वीकार कर दिया जाता है।

FAQ

क्या मुझे GB10 चाहिए?

हाँ, मॉडल चलाने के लिए। आपके बाकी कंप्यूटर इसके क्लाइंट की तरह चलते हैं: Linux (Arm या x86) और macOS उसी इंस्टॉल कमांड से, Windows (Arm या x86, प्रीव्यू) PowerShell की लाइन से।

क्या यह सच में मुफ़्त है?

हाँ। Ragon AGPL के तहत ओपन सोर्स है, और मॉडल के वेट्स मुफ़्त हैं। आपका एकमात्र चालू खर्च बिजली है।

मशीन के अलावा मुझे क्या चाहिए?

उसके साथ आने वाला OS (DGX OS 7, या Ubuntu 24.04 जहाँ विक्रेता देता है), NVIDIA Container Toolkit के साथ Docker, Python 3 और Git। सादे Ubuntu पर ragon-admin host check बता देता है कि क्या कम है।

क्या कुछ कभी इंटरनेट तक पहुँचता है?

सिर्फ़ वही जो आप या एजेंट माँगें, जैसे आपकी अपनी मशीन पर SearXNG के ज़रिए वेब सर्च, और पहली बार के डाउनलोड। /airgapped on यह सब बंद कर देता है।

यह कौन-सा मॉडल चलाता है?

NVIDIA के 4-बिट NVFP4 फ़ॉर्मैट में Qwen3.8-27B, हमारे इंजन ragon-serve पर DFlash2 ड्राफ़्टर के साथ (पूरे 0.9.x में SGLang फ़ॉलबैक के रूप में रहता है), GB10 के लिए चुना और ट्यून किया हुआ। करीब 20 GB के वेट्स; चलते समय मशीन की लगभग 38 GB मेमोरी खाली रहती है।

अपना कोड अपनी डेस्क पर रखें

अगर आप मानते हैं कि कोड को उसी डेस्क पर रहना चाहिए जहाँ वह लिखा गया, तो रिपॉज़िटरी को स्टार करें: इसी तरह दूसरे GB10 मालिकों को Ragon मिलता है।

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
