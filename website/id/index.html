Instal

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # mengunduh model sekali (~20 GB), lalu menjalankannya
$ cd ~/your-project && ragon    # selesai, itu saja

Berjalan di NVIDIA DGX Spark dan semua mesin GB10. Skrip memverifikasi setiap unduhan dengan checksum rilis dan menampilkan setiap perintah sudo sebelum menjalankannya. Baca dulu kalau Anda mau.

Klien Mac dan Linux

Komputer Anda yang lain memakai model di GB10 lewat jaringan lokal. Di Mac atau mesin Linux lain, perintah yang sama di atas memasang klien ragon; klien ini menemukan GB10 secara otomatis.

Klien Windows pratinjau

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

Di PowerShell. Dipasang tanpa hak administrator, lalu Windows meminta satu kali untuk menyiapkan sandbox agen. Belum ditandatangani secara digital, jadi Smart App Control harus nonaktif. Baca skripnya.

Cara instalasi lain

Halaman rilis juga menyediakan dmg untuk Mac (Ragon-<version>-arm64-preview.dmg, atau x64 untuk Intel) dan penginstal Windows (Ragon-Setup-<version>-x64.exe, atau arm64). Keduanya pratinjau tanpa tanda tangan: bila diunduh lewat browser, akan dihentikan saat pertama kali dibuka. Periksa masing-masing dengan SHA256SUMS rilis yang bertanda tangan terlebih dulu.

  • macOS 15 ke atas: seret Ragon ke Applications dan buka sekali, lalu System Settings › Privacy & Security › Open Anyway. Di macOS 14 dan lebih lama, Control-klik aplikasi › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control harus nonaktif.

Coba ini dulu

Atau antrekan pekerjaan untuk malam ini dengan /night add <task>: Ragon mengerjakan antrean saat Anda tidur, setiap tugas di branch git-nya sendiri, dan Anda meninjau branch itu sambil minum kopi.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Kode Anda tidak pernah meninggalkan meja Anda — dan Anda bisa membuktikannya

Agen coding cloud mengirim kode sumber Anda ke server milik pihak lain. Ragon tidak mengirimnya ke mana pun: model berjalan di GB10 Anda, dan tidak ada bagian Ragon yang menghubungi pihak luar. Tanpa analitik penggunaan, tanpa metrik, tanpa sign-in, tanpa laporan crash "anonim". Itu membuatnya bisa dipakai untuk kode yang tidak boleh Anda unggah: pekerjaan klien, data yang diatur regulasi, produk yang belum dirilis.

Satu perintah menjalankan sesi Ragon sungguhan di bawah strace dan mendaftar setiap koneksi jaringan yang dibuatnya:

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Semuanya tetap di 127.0.0.1. Tidak satu pun pencarian DNS.

Butuh jaminan mutlak?

Ketik /airgapped on dan setiap perintah yang dijalankan agen mendapat network namespace kosong dari kernel Linux. Ini bukan permintaan sopan kepada model: memang tidak ada jaringan yang bisa dijangkau. Full Access, yang akan melewati sandbox, ditolak pada saat yang sama.

Apa yang bisa keluar, dan kapan

Hanya yang Anda atau agen minta: pencarian web (lewat SearXNG privat di mesin Anda sendiri), pengambilan halaman, permintaan baca-saja ke akun Google yang Anda hubungkan, atau pengecekan pembaruan. Pada /airgapped on, tidak satu pun.

FAQ

Apakah saya butuh GB10?

Ya, untuk menjalankan modelnya. Komputer Anda yang lain memakainya sebagai klien: Linux (Arm atau x86) dan macOS dengan perintah instalasi yang sama, Windows (Arm atau x86, pratinjau) dengan baris PowerShell.

Benarkah gratis?

Ya. Ragon bersumber terbuka di bawah AGPL, dan bobot modelnya gratis. Satu-satunya biaya operasional Anda adalah listrik.

Apa yang saya butuhkan selain mesinnya?

OS bawaannya (DGX OS 7, atau Ubuntu 24.04 jika vendor menawarkannya), Docker dengan NVIDIA Container Toolkit, Python 3, dan Git. Di Ubuntu biasa, ragon-admin host check memberi tahu apa yang kurang.

Apakah ada yang pernah menjangkau internet?

Hanya yang Anda atau agen minta, seperti pencarian web lewat SearXNG di mesin Anda sendiri, dan unduhan pertama kali. /airgapped on mematikan semuanya.

Model apa yang dijalankannya?

Qwen3.8-27B dalam format NVFP4 4-bit NVIDIA, dilayani oleh mesin kami ragon-serve dengan drafter DFlash2 (SGLang tetap menjadi cadangan sepanjang 0.9.x), dipilih dan disetel untuk GB10. Bobot sekitar 20 GB; sekitar 38 GB memori mesin tetap bebas selama melayani.
