Sakinisha

$ curl -fsSL https://github.com/dreamference/ragon/releases/latest/download/install.sh | bash
$ ragon-admin server start      # inapakua modeli mara moja (~20 GB), kisha inaihudumia
$ cd ~/your-project && ragon    # ndiyo yote

Inafanya kazi kwenye NVIDIA DGX Spark na kila mashine ya GB10. Hati hii inakagua kila upakuaji kwa checksum za toleo na inaonyesha kila amri ya sudo kabla ya kuiendesha. Isome kwanza ukipenda.

Clients za Mac na Linux

Kompyuta zako nyingine zinatumia modeli ya GB10 kupitia mtandao wa ndani. Kwenye Mac au mashine nyingine ya Linux, amri ile ile hapo juu inasakinisha client ya ragon; inaipata GB10 yenyewe.

Client ya Windows onyesho

> irm https://github.com/dreamference/ragon/releases/latest/download/install.ps1 | iex

Kwenye PowerShell. Inasakinisha bila haki za msimamizi, kisha Windows inauliza mara moja kuandaa sandbox ya wakala. Bado haijatiwa saini, kwa hivyo Smart App Control lazima izimwe. Soma hati.

Njia nyingine za kusakinisha

Ukurasa wa toleo pia una dmg ya Mac (Ragon-<version>-arm64-preview.dmg, au x64 kwa Intel) na kisakinishi cha Windows (Ragon-Setup-<version>-x64.exe, au arm64). Ni matoleo ya onyesho yasiyotiwa saini: yakipakuliwa kwenye kivinjari, yanazuiwa mara ya kwanza. Kagua kila moja kwa SHA256SUMS iliyotiwa saini ya toleo kwanza.

  • macOS 15 na mpya zaidi: buruta Ragon hadi Applications na uifungue mara moja, kisha System Settings › Privacy & Security › Open Anyway. Kwenye macOS 14 na ya zamani zaidi, bofya programu huku umeshika Control › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control lazima izimwe.

Jaribu hizi kwanza

Au panga kazi za usiku wa leo kwa /night add <task>: Ragon inafanya kazi za foleni wakati unalala, kila kazi kwenye git branch yake, na wewe unapitia branch hizo ukinywa kahawa.

$ ragon "explain this repository to me like I'm new on the team"
# reads the code index (ragon-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ragon "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ragon-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Msimbo wako haondoki mezani kwako — na unaweza kuthibitisha

Mawakala wa uandishi wa msimbo wa cloud hutuma msimbo wako wa chanzo kwenye seva za mtu mwingine. Ragon haupeleki popote: modeli inaendeshwa kwenye GB10 yako, na hakuna kitu ndani ya Ragon kinachowasiliana na seva za nje. Hakuna uchanganuzi wa matumizi, hakuna metriki, hakuna kuingia, hakuna ripoti za hitilafu za "bila jina". Hivyo inaweza kutumika kwa msimbo usioruhusiwa kuupakia: kazi za wateja, data iliyodhibitiwa, bidhaa ambazo hazijatolewa.

Amri moja inaendesha kikao halisi cha Ragon chini ya strace na kuorodhesha kila muunganisho wa mtandao uliofanywa:

$ ragon-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Kila kitu kilibaki kwenye 127.0.0.1. Hakuna hata ombi moja la DNS.

Unahitaji hakikisho kamili?

Andika /airgapped on na kila amri anayoendesha wakala inapewa network namespace tupu kutoka kwenye kernel ya Linux. Si ombi la heshima kwa modeli: hakuna mtandao wa kufikia kabisa. Full Access, ambayo ingeruka sandbox, inakataliwa wakati huo huo.

Nini kinaweza kutoka, na lini

Ni kile tu unachoomba wewe au wakala: utafutaji wa wavuti (kupitia SearXNG ya faragha kwenye mashine yako mwenyewe), kuleta ukurasa, ombi la kusoma tu kwa akaunti ya Google uliyounganisha, au ukaguzi wa masasisho. Kwenye /airgapped on, hakuna chochote kati ya hivyo.

Maswali yanayoulizwa mara kwa mara

Je, ninahitaji GB10?

Ndiyo, ili kuendesha modeli. Kompyuta zako nyingine zinaitumia kama clients: Linux (Arm au x86) na macOS kwa amri ileile ya usakinishaji, Windows (Arm au x86, onyesho) kwa mstari wa PowerShell.

Je, ni bure kweli?

Ndiyo. Ragon ni chanzo huria chini ya AGPL, na weights za modeli ni bure. Gharama yako pekee ya kuendelea ni umeme.

Ninahitaji nini mbali na mashine?

Mfumo wa uendeshaji unaokuja nao (DGX OS 7, au Ubuntu 24.04 pale muuzaji anapoutoa), Docker na NVIDIA Container Toolkit, Python 3 na Git. Kwenye Ubuntu ya kawaida, ragon-admin host check inakuambia kinachokosekana.

Je, kuna kitu kinafika mtandaoni?

Ni kile tu unachoomba wewe au wakala, kama utafutaji wa wavuti kupitia SearXNG kwenye mashine yako mwenyewe, na upakuaji wa mara ya kwanza. /airgapped on inazima yote.

Inaendesha modeli gani?

Qwen3.8-27B katika umbizo la NVFP4 la biti 4 la NVIDIA, inayohudumiwa na injini yetu ragon-serve pamoja na drafter ya DFlash2 (SGLang inabaki kuwa njia mbadala katika 0.9.x yote), iliyochaguliwa na kuboreshwa kwa GB10. Weights za takriban 20 GB; karibu 38 GB za kumbukumbu ya mashine zinabaki huru inapohudumia.
